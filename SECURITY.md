# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Use the
repository's private vulnerability reporting feature under **Security > Advisories > Report a
vulnerability**. Include reproduction steps, affected endpoints or files, expected impact, and any
suggested mitigation.

If a credential may have been exposed, revoke and rotate it immediately before sharing diagnostic
details. Do not include live secrets, private keys, database dumps, or personal data in the report.
