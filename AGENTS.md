# Project instructions

- Write all code and code comments in English.
- Do not use emojis in code, logs, API responses, or notification templates.
- Keep the application as a single-user modular monolith.
- Add sources through the `BaseSource` abstraction without coupling them to API or notification logic.
- Prefer deterministic behavior and explicit tests over hidden automation.
- Do not add live scraping, browser automation, or LLM integration without an approved source-specific task.
